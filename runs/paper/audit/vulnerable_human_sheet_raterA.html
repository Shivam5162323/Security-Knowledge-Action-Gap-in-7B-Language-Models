What to do

  1. Read each program and decide whether the weakness named on the item is present, using the rules below.
  2. Click Vulnerable or Not vulnerable. If the code does not settle it, give the more likely answer and tick Unsure.
  3. To save clicks, you can first press one of the Mark all unrated as buttons at the top, then read every program and change only the ones that should be the other way.
  4. When every item has a rating, press Download ratings and send back the file .

Work alone. Do not discuss items with the other rater, and do not look up which model wrote a program or what the automatic checks decided. Your progress is kept in this browser, so you can close the page and continue later. The downloaded file records which ratings were left as set by “mark all”.
